# Granule — внешние локализации

Этот набор — небольшой патч для **оригинальной Granule**. Он устанавливает загрузчик локализаций, переключатель языка в главном меню и русский перевод. Самой игры и `Granule.exe` в архиве нет.

## Установка

1. Полностью закройте Granule.
2. Распакуйте содержимое ZIP **в корневую папку оригинальной игры**, рядом с `Granule.exe`.
3. Подтвердите замену файлов.
4. Запустите игру и выберите `Русский` или `English` внизу главного меню.

## Как добавить язык

Откройте `resources/locales/` и положите туда отдельный UTF-8 JSON-файл. Например, `de.json`:

```json
{
  "name": "Deutsch",
  "translations": {
    "ENTER": "SPIELEN",
    "SETTINGS": "EINSTELLUNGEN",
    "EXIT": "BEENDEN",
    "Language": "Sprache"
  }
}
```

Перезапустите игру — `Deutsch` появится в списке. Для новых языков не нужно менять JavaScript, пересобирать игру или создавать новый патч. В архив также включён `template.json` как образец; он намеренно не отображается в выборе языка.

## Формат

- `name` — имя языка в переключателе.
- `translations` — пары «исходная английская строка»: «перевод».
- Ключи должны совпадать с исходным английским текстом игры.
- Отсутствующие переводы остаются на английском.
- Не удаляйте плейсхолдеры вида `{name}`, `{n}` или `{count}`.
- Сохраняйте файл в UTF-8. После добавления или изменения JSON перезапустите игру.

Все языковые словари в этом архиве содержат полный набор из 539 ключей текущей версии игры. В архив включены переводы: китайский (упрощённый), немецкий, эсперанто, испанский, французский, польский, русский, итальянский, португальский (Бразилия), японский, корейский, турецкий, нидерландский, украинский, арабский, чешский, греческий, шведский, вьетнамский, индонезийский, хинди, тайский, румынский, датский, финский и венгерский. Плейсхолдеры вроде `{name}` сохранены. Для строк, добавленных будущими обновлениями или модами, могут потребоваться новые ключи.
